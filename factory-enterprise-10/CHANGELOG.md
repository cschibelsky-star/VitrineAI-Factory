- Novo Design System Vitrine IA Pro.
- Novo layout base Enterprise.
- Novo Dashboard/Cockpit Executivo.
- Interface Comercial modernizada.
- Clientes 360 modernizado.
- Factory Studio com visual de build, QA e deploy.
- Marketplace com visual de catálogo premium.
- Analytics com cockpit executivo.
- Script instalador com backup automático.
- Instruções de instalação e homologação.

## Preservado
- Banco de dados existente.
- Regras de negócio existentes.
- Módulos atuais.
- Fluxos comerciais atuais.
- Licenças, clientes e produtos já cadastrados.

## Observação técnica
Este pacote não recria a plataforma. Ele aplica uma camada visual Enterprise e prepara a Factory para homologação da versão 10.0.
