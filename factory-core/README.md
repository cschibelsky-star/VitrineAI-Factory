# Factory Core 0.1

Primeira base executável do **Factory Engineering Center**.

Objetivo: criar o núcleo mínimo para a Factory rodar e começar a organizar produtos, blueprints, capabilities, agents, engines e missions.

## Módulos da Build 0.1

- Products
- Blueprints
- Capabilities
- Agents
- Engines
- Missions
- Builder básico

## Estratégia

A Factory Core 0.1 será implementada como base Laravel + Filament, reaproveitando padrões já usados no ecossistema Vitrine AI Pro.

## Produtos fundadores

- TV Digital Enterprise
- Guia Digital
- Portal News
- Portal Câmara

## Próximo passo técnico

Aplicar as migrations, models e resources Filament desta pasta dentro do projeto Laravel que será usado como base da Factory.
