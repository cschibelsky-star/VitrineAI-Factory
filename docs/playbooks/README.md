# Factory Engineering Playbooks

Os Playbooks são os guias oficiais de execução da Vitrine AI Factory.

Eles respondem como executar, passo a passo, os processos de engenharia definidos pela Constituição e pelos Engineering Standards.

## Volumes iniciais

- Volume LXI — Product Creation Playbook
- Volume LXII — Agent Creation Playbook
- Volume LXIII — Engine Creation Playbook
- Volume LXIV — Blueprint Creation Playbook

## Função

Cada Playbook deverá conter:

- Objetivo.
- Filosofia.
- Etapas oficiais.
- Checklist.
- Indicadores.
- Governança.
- Critérios de implementação.

Nenhum processo de engenharia deverá ocorrer fora dos Playbooks oficiais.
