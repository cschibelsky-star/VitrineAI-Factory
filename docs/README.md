# Vitrine AI Factory — Documentação Oficial

Este diretório é a fonte oficial da documentação da **Vitrine AI Factory**.

A documentação será organizada em coleções:

1. **Constituição Oficial** — visão, princípios, governança e arquitetura institucional.
2. **Engineering Standards** — padrões oficiais de implementação.
3. **Factory Engineering Playbooks** — guias operacionais de execução.
4. **Reference Architecture** — arquitetura técnica e organização do código.
5. **Catalogs** — Blueprints, Capabilities, Skills, Agents e Product DNA.

## Regra oficial

Toda evolução da Factory deverá retornar para esta documentação como conhecimento versionado, reutilizável e auditável.
