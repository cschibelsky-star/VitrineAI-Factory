# FACTORY PACKAGE 8.0 — Enterprise Factory Intelligence

Pacote completo para evoluir a VitrineAI Factory sem quebrar o núcleo já estável.

Inclui:
- Factory Intelligence Service
- Deploy Center
- Marketplace de Templates
- Pipeline Visual
- Dashboard operacional avançado
- Migrations de inteligência para templates e projetos
- Seeder de templates enterprise

Aplicação recomendada: copiar o conteúdo deste pacote para a raiz do projeto `~/factory.vitrineiapro.com.br`, rodar migrations, seed e limpar cache.

Este pacote evita substituir o `FactoryProjectResource.php` para não reintroduzir erro 500 no CRUD já estável.
